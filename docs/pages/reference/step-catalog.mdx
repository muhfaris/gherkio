## JSON Payload Helpers

Use either of the following steps when you need to post a request body:

- `I call API "<key>" with body:` expects a docstring (the `""" … """` block). Whatever you place inside the docstring is sent verbatim after rendering any template expressions. This is ideal for structured payloads that need nesting or non-JSON formats.

  ```gherkin
  When I call API "documents.create" with body:
    """
    {
      "code": "{{ .store.document_code }}",
      "name": "{{ .store.document_name }}",
      "description": "{{ .store.document_description }}"
    }
    """
  ```

  Each `{{ .store.* }}` placeholder resolves using the current scenario store, so you can reuse data captured in previous steps.

- `I call API "<key>" with:` is a shortcut that converts a data table directly into JSON after rendering template expressions in each cell. It works well for flat key/value pairs.

  ```gherkin
  When I call API "auth.login" with:
    | username | {{ .store.username }} |
    | password | {{ .store.password }} |
  ```

Both variants now share the same templating engine, so choose whichever format matches the payload you want to send.

> **Tip:** Any JSON path argument (e.g., `json '$.data.id' should exist`) also supports templating, so you can write expressions like `json '$.data.#(code=="{{ .store.document_file_code }}")' should exist` to match values saved in the store.
