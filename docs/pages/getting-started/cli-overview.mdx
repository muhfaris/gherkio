# CLI Overview

| Command | Purpose |
| ------- | ------- |
| `gherkio init` | Scaffold the project structure under `gherkio/`. |
| `gherkio call` | Invoke a single API defined in catalog YAML. |
| `gherkio run` | Execute Gherkin features via Godog integration. |
| `gherkio steps` | List available step bindings and examples. |
| `gherkio import` | Convert a curl command (JSON or multipart) into catalog/fixture/feature scaffolding. |

Use `gherkio <command> --help` for detailed flags. The [CLI Reference](../reference/cli-command) covers all options, reporters, and workflows.
