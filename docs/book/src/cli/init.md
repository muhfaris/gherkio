# gherkio init

Initialize a new Gherkio project structure

### Synopsis

Creates the .gherkio directory in the current working directory
with the default project structure including config, environments, tests,
reports, and schemas.

```
gherkio init [flags]
```

### Options

```
  -h, --help   help for init
```
